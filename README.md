# Pokemon CardRush Price Overlay (Chrome Extension, MV3)

在浏览 https://www.pokemon-card.com/ 时，显示 CardRush Pokémon 对应卡牌各版本价格。

## 功能

### 第一阶段（MVP）
- 卡牌详情页自动识别卡名
- 请求 CardRush 搜索页并解析价格
- 在详情页插入 `CardRush 価格情報` 区块

### 第二阶段（已包含基础实现）
- 搜索页 hover 浮窗
- 内存 + `chrome.storage.local` 缓存
- 请求防抖、并发去重（同名卡共享同一 Promise）
- 多稀有度聚合 + 状态优先级（通常 > A > A-/B/C/傷あり等）

## 安装方式（开发者模式）

1. 下载/创建本项目目录
2. 打开 Chrome：`chrome://extensions/`
3. 打开右上角「开发者模式」
4. 点击「加载已解压的扩展程序」
5. 选择项目根目录（含 `manifest.json`）
6. 打开宝可梦官网卡牌页进行测试

## 测试方式

### 详情页
- 打开示例详情页：
  - `https://www.pokemon-card.com/card-search/details.php/card/50106/regu/XY`
- 检查页面是否出现 `CardRush 価格情報`
- 检查是否显示多版本价格、库存状态、链接

### 搜索页
- 打开示例搜索页：
  - `https://www.pokemon-card.com/card-search/index.php?...`
- 鼠标悬停某张卡牌
- 检查是否出现价格浮窗，移出后约 400ms 关闭
- 重复悬停同一卡牌，观察是否明显减少重复请求（命中缓存）

## 数据规则说明

- 状态识别：
  - 有损：`A-`, `B`, `C`, `状態A-`, `状態B`, `状態C`, `傷あり`, `キズあり`, `プレイ用`, `状態難`
  - 无损优先：无状态、`通常品`, `美品`, `状態A`
- 库存识别：
  - `売り切れ`, `品切れ`, `在庫なし` => 无库存
  - `在庫あり`, `カートに入れる` => 有库存
- 即使无库存，仍展示价格

## 已知限制

1. CardRush 页面结构若变动，解析器可能需更新选择器和文本规则。
2. 搜索页卡牌 hover 的 DOM 结构在官网不同活动页可能不一致，已做多策略兜底，但仍可能漏识别。
3. 部分商品标题稀有度标记不标准时，可能归类为 `その他`。
4. 某些情况下内容脚本直接抓取可能受站点策略影响，已加入 `background.js` 代理抓取兜底。
5. 目前未实现设置页（缓存时间/过滤受损/是否显示无库存）；可在下一阶段扩展 options 页面。
